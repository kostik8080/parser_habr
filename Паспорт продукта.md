# Паспорт продукта: парсер-робот публичной активности статей

**Дата:** 15.11.2026

---

## 1. Назначение

Парсер-робот, который следит за публичной активностью статей, на которые подписан пользователь, и присылает сводку в одном месте — чтобы не приходилось искать информацию по всему сайту.

## 2. Ниша

Авторы с темами по:
- искусственному интеллекту
- ИИ
- программированию
- фронтенд-разработке

## 3. События (что отслеживается)

- Реакции / лайки / голоса на статье
- Публикация новой статьи автором
- Обновления / правки статьи
- Появление статьи в подборках / коллекциях

## 4. Исключения (что отсекается)

- Личные сообщения автора
- Реклама
- Просмотры (если бы такая метрика существовала)
- Комментарии (не входят в события)

## 5. Доставка сводки

| Параметр | Значение |
|----------|----------|
| Кому | Только пользователю |
| Куда | Telegram + email |
| Частота | Ежедневно |

## 6. Критерий полезности

Сводка считается полезной, если:
1. Экономит время на поиск информации
2. Гарантирует, что ничего важного не пропущено
3. Короткая и по делу
